# Priority Roadmap

This roadmap is built from your starred repositories and focuses on the most practical learning path first.

## Phase 1: AI / LLM foundation (Start here)

### Goal
Build a strong base in AI tools, LLM workflows, and agentic patterns without getting lost in too many tools.

### Recommended repos
- browser-use — learn the practical side of AI agents interacting with the browser
- awesome-llm-apps — explore real examples of useful LLM applications
- OmniRoute — understand model access and routing across providers
- openwork — see a collaborative AI workflow approach
- graphify — learn how codebases can be turned into queryable systems

### Suggested sequence
1. Read the overview pages for browser-use and awesome-llm-apps
2. Try one simple AI workflow using browser-use or a similar library
3. Use OmniRoute to compare multiple models/providers in a lightweight way
4. Explore graphify once you want to understand codebase intelligence
5. Keep openwork as a future experimentation path

### Outcome
You’ll know how people actually build AI workflows, agents, and tool-using systems.

## Phase 2: Learning structure (Add discipline)

### Goal
Set a learning plan so the AI work is grounded in strong engineering fundamentals.

### Recommended repos
- AI-For-Beginners — great beginner-friendly structure
- developer-roadmap — choose the next step in your training path
- freeCodeCamp — practical exercises and foundational skills
- project-based-learning — learn by building instead of only reading

### Suggested sequence
1. Start with AI-For-Beginners to grasp concepts without overload
2. Follow developer-roadmap to identify gaps in your current skills
3. Use freeCodeCamp for defined learning exercises
4. Add project-based-learning for hands-on practice

### Outcome
You’ll have a structured path that keeps your learning practical and sustainable.

## Phase 3: Build and practice

### Goal
Turn curiosity into real projects instead of collecting tools without using them.

### Recommended repos
- build-your-own-x — best for deep understanding by rebuilding systems
- app-ideas — generate project directions
- awesome-project-ideas — find AI and ML-specific concepts
- Project-Ideas-And-Resources — practical project backlog source

### Suggested sequence
1. Pick 1–2 project ideas that excite you
2. Build something small but real
3. Revisit build-your-own-x for deeper learning when you hit a wall
4. Maintain a project backlog using the idea repos

### Outcome
You’ll move from learning to doing and start building things you can show or reuse.

## Phase 4: Reference and ecosystem discovery

### Goal
Keep a useful library of APIs, knowledge, and tooling for future projects.

### Recommended repos
- Public-APIs
- public-apis
- awesome
- free-programming-books

### Suggested sequence
1. Browse APIs when you want a quick idea for a project
2. Use awesome for discovery across any topic
3. Keep free-programming-books as your reading backlog

### Outcome
You’ll always have fast access to the ecosystem around your main learning direction.

## Weekly rhythm

A very practical way to use this list is:

- Monday: AI/LLM learning block
- Tuesday: Coding/building block
- Wednesday: Project idea or API exploration
- Thursday: Deep-dive on one technical topic
- Friday: Build or refine one small prototype
- Weekend: Review resources and plan the next week

## Final recommendation

Your starred list is strongest in AI + learning + project inspiration. The best strategy is not to chase every repo you’ve starred. Instead:

- Start with the AI/LLM repos
- Learn in a structured way
- Build something real
- Keep the reference repos nearby for inspiration

This gives you a sustainable system instead of an endless backlog.
