# Learning & Career Growth

This category is focused on becoming stronger at software engineering, learning broadly, and preparing for technical interviews or system design conversations.

## Core repos

### project-based-learning
- Purpose: Curated project-based tutorials
- Best for: Learning by building
- Use case: Choose a project and learn by doing rather than just reading theory

### awesome-python
- Purpose: Python ecosystem guide
- Best for: Identifying packages, frameworks, and patterns
- Use case: Quickly find the best tool for Python tasks

### coding-interview-university
- Purpose: Full software engineering study plan
- Best for: Technical interview prep
- Use case: Structured path to CS fundamentals and interview preparation

### developer-roadmap
- Purpose: Developer growth roadmaps
- Best for: Long-term skill tracking
- Use case: Identify what to learn next in backend, frontend, AI, or infrastructure

### system-design-primer
- Purpose: System design prep and education
- Best for: Architecture and scaling interview prep
- Use case: Learn how large systems are designed and discussed

### free-programming-books
- Purpose: Free programming books library
- Best for: Reading and self-study
- Use case: Build a reading backlog without paying for formal courses

### freeCodeCamp
- Purpose: Open-source learning platform
- Best for: Structured learning across multiple languages and topics
- Use case: Learn programming and CS fundamentals from scratch

### build-your-own-x
- Purpose: Recreate technologies from scratch
- Best for: Deep understanding
- Use case: Learn how systems work by reimplementing them yourself

### AI-For-Beginners
- Purpose: Beginner-friendly AI learning curriculum
- Best for: Getting into AI concepts without overwhelm
- Use case: Learn the foundations of machine learning and AI with a structured course

## Suggested learning path

- If you're brand new: AI-For-Beginners + freeCodeCamp
- If you want hands-on growth: project-based-learning + build-your-own-x
- If you want stronger engineering depth: coding-interview-university + system-design-primer

## Strategic takeaway

This area gives you both the learning structure and the self-directed project momentum needed to grow quickly.
