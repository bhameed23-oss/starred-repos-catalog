# AI / LLM / Agent Tools

This category is the strongest signal in the starred list. These repositories are useful for experimentation, agent workflows, reasoning systems, local model execution, and AI-powered engineering workflows.

## Core repos

### browser-use
- Purpose: Browser automation for AI agents
- Best for: Agentic browsing, web research, task automation
- Use case: Let an AI open a website, navigate, click, and complete action flows

### laya
- Purpose: Decision engine / reasoning system for text workflows
- Best for: Agentic classification, scoring, and decision pipelines
- Use case: Reasoning over large text sets using structured decisioning

### open-code-review
- Purpose: Code review automation using hybrid agents and rules
- Best for: Automated PR review and code quality checks
- Use case: Catch logic bugs, thread safety issues, SQL injection patterns, etc.

### colibri
- Purpose: Run frontier MoE models locally on existing hardware
- Best for: Self-hosted inference
- Use case: Use large models without depending only on hosted APIs

### spec-kit
- Purpose: GitHub toolkit for structured engineering workflows
- Best for: Product/engineering process design and spec-driven development
- Use case: Define requirements and iterate on product specs with tooling support

### OpenViking
- Purpose: Memory and context architecture for AI agents
- Best for: Persistent agent knowledge systems
- Use case: Build context-aware AI agents with long-term memory

### OmniRoute
- Purpose: One gateway to many AI providers and models
- Best for: Model routing and access abstraction
- Use case: Easier multi-model experimentation and fallback strategies

### graphify
- Purpose: Convert codebases into queryable knowledge graphs
- Best for: Understanding complex repositories and systems
- Use case: Ask structured questions about code structure, relationships, and docs

### awesome-llm-apps
- Purpose: Large curated list of LLM apps and agent examples
- Best for: Learning and inspiration
- Use case: See patterns for building practical AI apps

### openwork
- Purpose: Open-source collaborative AI workflow tool
- Best for: AI-assisted work environments
- Use case: Build a local coworker-style AI workflow stack

## Recommended stack for a beginner

- Start with: browser-use, awesome-llm-apps, OmniRoute
- Add later: graphify, OpenViking, open-code-review

## Strategic takeaway

This is the most relevant set if your goal is to build or deeply understand AI-powered workflows.
