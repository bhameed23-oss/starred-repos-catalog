# Developer Resources & Tooling

These repos are less about building a specific app and more about building better reference systems, understanding the ecosystem, and staying productive.

## Core repos

### Public-APIs
- Purpose: Curated list of public APIs
- Best for: Finding APIs to integrate into projects
- Use case: Quickly identify available public services for product ideas

### public-apis
- Purpose: Community-driven directory of free APIs
- Best for: Ecosystem discovery
- Use case: Find API-based project opportunities or integrations

### awesome
- Purpose: Master list of curated awesome repositories
- Best for: General discovery
- Use case: Explore any topic from a single reliable index

### skills
- Purpose: Skills library for designers and engineers
- Best for: Building product and design capabilities
- Use case: Learn practical skill patterns and working methods

## Best use strategy

Keep these as your reference stack:

- Public APIs for product ideas
- awesome for topic exploration
- skills for capability growth

## Strategic takeaway

This category gives you a strong “research + reference” backbone alongside the learning and AI categories.
